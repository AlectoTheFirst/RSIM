# `rsim-ingest`, Equinix

The Equinix module is in `equinix/`: `reader.rs` reads the Fabric ports, the connections of `connections` and `edge_connections`, the Network Edge devices of `edge_devices` and the device link groups of `edge_links`, `coverage.rs` classifies their nested paths with `*` for each element of a list, and `lower.rs` gives each Fabric port `port/<uuid>` of the account device a gate `port/<uuid>/in`, an `AclMatch` with one rule for the tags of each leg and a last unhandled rule, and a `Circuit` `port/<uuid>/circuit`. A port is lowered when its state is `ACTIVE` and its encapsulation is `DOT1Q`, `QINQ` or `UNTAGGED`, with the TPID of `tagProtocolId` (default `0x8100`, `0x88a8` for QinQ). A circuit of the type `EVPL_VC` in the state `ACTIVE` with both ends on lowered ports is lowered: `DOT1Q` gives one tag, `QINQ` the S-tag with the TPID of its port over the C-tag, and `UNTAGGED` and `NULL` a port-based leg (`CircuitLeg::port_based`) when both ends are port-based. The states of `ENDED_STATES` give no leg. Each other case, a service profile end, a far port outside the account, 2 items of one uuid that differ, a hairpin circuit and 2 circuits with the same tags on one port send the frames of the legs to the sink `circuit/<uuid>/sink` with the reason; a far port with no link peer sends them to `port/<uuid>/unbound`.

`edge.rs` holds the Network Edge part. A Network Edge interface that a circuit or a device link group uses is the account port `ne-<device uuid>/<interface id>`. A `VD` end with no link protocol on an interface of a Network Edge device of the account joins the one tag of the Fabric end to the untagged interface: `ne-<...>/in` pushes the tag (`TagOp::Push`) before the `Circuit` `ne-<...>/circuit`, and the leg of the Fabric port ends at `ne-<...>/out`, which pops the tag (`TagOp::Untag`) before the link peer of the account port. A `VD` end with a link protocol, a circuit between 2 Network Edge interfaces, a `VD` end with a port-based or 2-tag Fabric end, an end on a device outside the account, an end that names no interface, an end with no `edge_devices` section, and an interface in more than one circuit or device link group give `Unknown`. A device link group in the state `PROVISIONED` is the bridge domain `link-group/<uuid>`: each member port has a gate that makes a tagged frame unknown, a `PortIngress`, and a `PortEgress` to its link peer. The `MacLookup` sends a frame to the member with its MAC. Its flood successor sends each frame of a group of 2 members, and only a broadcast frame of a larger group, to the `Flood`. A member outside the account is a sink. Each other state makes the member ports unknown.

The section `bindings` of an account holds the bindings of its Fabric ports from the inventory records `fabric_port_bindings` of the account, which the Equinix source writes with no read; `equinix::summary` gives the gates of the Fabric ports as the entries and each binding as a `links::Binding`. The join links each binding to the lowered port of the device that it names with no record at the far end, removes each other link of its 2 ends with a note, and gives a note for a device or a port that the twin does not have; the account lowering then sends the frames of a circuit to the entry of the bound port of the far Fabric port. The join also links a port whose description (`Summary::descriptions`, from the `description` line of an interface of NX-OS, IOS-XE, IOS-XR and VyOS) names one Fabric port of `Summary::fabric_ports` by the rule of HST (`links::names_fabric_port`), when the description states no cable id (`links::cable_ids`) or a cross connect id of the port; a description of 2 Fabric ports, a Fabric port of 2 descriptions and a stated cable id that is no cross connect id give a note and no link, and an operator binding wins.

The section `bindings` also holds the bindings of the Network Edge devices from the inventory records `edge_device_bindings`. A binding names a Network Edge device by its uuid, else by its name or host name, with case ignored. A Network Edge device that no binding names is the twin device `<account>-ne-<uuid>`, whose port for each used interface is a sink with the reason `the Network Edge device <name> is not collected`. `equinix::summary` gives its summary and a binding record from each account port to it. An interface of a bound device binds to the one port of the bound device with its MAC (`equinix::mac_bindings`, which the estate runs before the join). An interface with no MAC, or a MAC on no port or on more than one port, gives a note and no link. A pair or a cluster of Network Edge devices is not detected, and each device is lowered alone.
